# Оценка стоимости недвижимости — приложение Streamlit

Приложение к проекту «Прогнозирование стоимости недвижимости» (Этап 4). Без API: всё работает внутри одного Streamlit-приложения.

## Что внутри
| Вкладка | Содержимое |
|---|---|
| **Прогноз стоимости** | форма (тип объявления, тип объекта, город → район → квартал, площадь, комнаты, возраст, этажи, отопление, месяц), проверка ввода, кнопка «Рассчитать», прогноз + 80 %-й диапазон + положение прогноза среди похожих объявлений |
| **Дашборд** | фильтры (тип объявления, города, типы объектов, площадь), KPI, 8 графиков по данным, выгрузка CSV; вложенная вкладка «Модели и качество»: таблица метрик 4 моделей, сравнение, «прогноз vs факт», важность признаков |
| **Справка** | как пользоваться, описание полей, модель и её ограничения, авторство, версия |

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```
> Модель сохранена в `scikit-learn 1.8.0` / `pandas 3.0.2` (нужен Python ≥ 3.11). При другой версии sklearn файл `artifacts/final_model.joblib` может не открыться — установите версии из `requirements.txt` или заново выполните ноутбук `MachineLearning_fixed.ipynb` в своём окружении и замените папку `artifacts/`.

## Структура
```
app.py                    интерфейс (3 вкладки)
utils.py                  логика: загрузка модели, проверка ввода, прогноз, диапазон
charts.py                 графики дашборда (matplotlib)
real_estate_features.py   предобработка и признаки (тот же модуль, что в ноутбуке; нужен для загрузки модели)
prepare_app_data.py       однократная подготовка app_data/ из исходных данных
artifacts/                final_model.joblib, model_metadata.json
app_data/                 выборка для дашборда, справочники формы, интервалы, метрики
test_logic.py             проверка логики и построения всех графиков
test_app_smoke.py         проверка выполнения app.py на заглушке Streamlit
tests_data/               20 тестовых объектов и их прогнозы из отчёта (для test_logic.py)
```

## Технические моменты
* Модель и данные загружаются **один раз** (`st.cache_resource` / `st.cache_data`), а не при каждом нажатии.
* Проверка ввода: обязательные поля (площадь, комнаты, расположение), диапазон площади 10–5 000 м², этаж не выше этажности. Ошибки показываются понятным текстом; необязательные поля можно оставить «не указано».
* Диапазон прогноза — 10-й и 90-й перцентили реальных ошибок (в log-шкале) модели, обученной на train, на тестовой выборке отдельно для продажи и аренды. Это не строгий доверительный интервал.
* Случайные состояния зафиксированы (`random_state=42`), версии зависимостей — в `requirements.txt`.

## Проверка
```bash
python test_logic.py        # модель из файла воспроизводит 20 прогнозов из отчёта, валидация, 14 графиков
python test_app_smoke.py    # app.py выполняется целиком (Streamlit подменяется заглушкой)
```

## Пересборка данных приложения (необязательно)
```bash
python prepare_app_data.py real_estate_data_csv.zip test_real_estate_samples.csv MachineLearning_fixed.ipynb
```
Скрипт повторяет очистку и разбиение из ноутбука (метрики совпадают с отчётом) и пересоздаёт `app_data/`.
